# Kebun Makna

A free farm game for learning the meaning and recitation of Juz 30, now with family accounts and a social feed built on verified sources (the Qur'an, Sahih Bukhari, Sahih Muslim).

- Live (classic): https://rickysaif.github.io/kebun-makna/
- New version in development: https://rickysaif.github.io/kebun-makna/beta/
- Backend: Supabase (`supabase/`). Build brief: `CLAUDE.md`, plan: `docs/PLAN.md`.
