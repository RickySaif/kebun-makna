# Daftar sumber konten cerita (untuk ustaz)

Ustaz meninjau seluruh versi beta (https://rickysaif.github.io/kebun-makna/beta/) sebelum Ricky memindahkannya ke versi utama. Dokumen ini hanya daftar: setiap cerita baru dan sumber (`sources.id`) yang dikutipnya. Teks Arab dan terjemahan di game diambil langsung dari pustaka `sources`, tidak diketik ulang.

Catatan penomoran hadis: nomor Bukhari/Muslim memakai **penomoran Lidwa Pusaka**, yang bisa berbeda dari penomoran sunnah.com / Fuad Abdul Baqi. Periksa teksnya, bukan hanya nomornya. File cerita ada di `content/akhlak/*.json`.
